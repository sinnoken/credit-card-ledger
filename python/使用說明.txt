信用卡帳單轉 Excel — 使用說明

【第一次使用】
1. 安裝 Python：在 PowerShell 執行  winget install Python.Python.3.12
2. 雙擊「1_安裝套件.bat」（約 150 MB，只需一次）

【每月使用】
1. 把帳單放進本資料夾，右鍵 decrypt_pdf.ps1 →「用 PowerShell 執行」，依提示輸入密碼（不會存檔），解開的檔案在 decrypted 資料夾
2. 雙擊「2_轉換帳單.bat」
3. 結果在 output 資料夾：信用卡明細_日期時間.xlsx
   - 固定 / 浮動：欄位同你的活頁簿（日期、消費類型、摘要、消費方式、分期數、金額）
   - 核對結果：每份帳單的金額核對，紅底代表對不上
   - 黃底＝類型是程式猜的；藍底＝摘要來自 OCR，可能有錯字

【調整】（用記事本打開 convert.py，最上面的「設定」區）
- DATE_MODE：日期用 "帳單日"（預設）、"消費日" 或 "入帳日"
- RULES：關鍵字 → 消費類型
- BANK_CARD / CARD_BY_LAST4：卡片名稱
- 分類參考.xlsx：你的既有紀錄。改過分類後把新紀錄貼進去，下次會照著分

支援：台北富邦、中國信託、兆豐、台新、第一銀行、合作金庫、臺灣銀行
